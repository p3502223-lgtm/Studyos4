# Study OS 4

A functional, mobile-friendly student productivity app using Vanilla JavaScript and local storage.

## Features
- **Student Dashboard:** View daily study progress, countdowns, and upcoming tasks.
- **Study Planner:** Add, manage, and track daily tasks.
- **Subjects & Syllabus:** Track your mastery progress across chapters and subjects.
- **Pomodoro Timer:** Utilize focus blocks (Pomodoro, Short/Long Break) to accumulate study hours.
- **Active Revision:** Interactive spaced-repetition flashcards to memorize concepts.
- **Profile & Data Management:** Toggle Dark Mode, set daily targets, and Backup/Restore your entire application data using JSON files.

## Running the App Locally
Since this is a fully static application, you can simply open `index.html` in your web browser. No server setup is required. The app persists your data locally in the browser.

## Deployment with GitHub Pages (Free)
You can deploy this application for free using GitHub Pages.

1. **Upload to GitHub:**
   - Create a new public repository on GitHub (e.g., `study-os-4`).
   - Upload all the files from this folder directly into the root of your new repository.
2. **Enable GitHub Pages:**
   - Go to your repository on GitHub.
   - Click the **Settings** tab.
   - On the left sidebar, click on **Pages**.
   - Under the "Build and deployment" section, choose **Deploy from a branch**.
   - In the "Branch" dropdown, select your main branch (`main` or `master`) and select `/ (root)`.
   - Click **Save**.
3. **Access Your App:**
   - Wait 1-2 minutes. GitHub will provide you with a live URL (e.g., `https://your-username.github.io/study-os-4/`).
   - Open this URL on your mobile browser. You can "Add to Home Screen" to use it as an app!
